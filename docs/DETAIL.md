# 求职助手（dsh-find-job）

求职助手：剖析能力、批量分析职位、一键生成打招呼语、调整简历。

帮正在找工作的你：批量识别值得投递的职位，匹配理由、打招呼语、简历改写一次到位。
帮在职观望的你：批量看清与意向职位的差距，缺什么一目了然。

全程本地运行、本地存储。

## 数据

数据存在 `~/.find-job/job_matcher.db`，首次使用自动创建。

## Chrome 插件（可选）

在 BOSS直聘 / 猎聘 职位详情页点「存入职位库」，把职位自动保存到本地 find-job。

插件在插件包的 `find-job/` 文件夹里，加载方式：`chrome://extensions` → 打开「开发者模式」→「加载已解压的扩展程序」→ 选择该文件夹。
