# find-job（Chrome 插件）

在 BOSS直聘 / 猎聘 的职位详情页点「存入职位库」，把职位自动保存到本地 find-job。

## 安装

1. 打开 Chrome，地址栏输入 `chrome://extensions`
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（插件包里的 `find-job/` 文件夹）

## 使用前提

- DSH 应用正在运行（find-job 插件会在本机 `127.0.0.1:18999` 提供写入端口）

## 使用方式

1. 打开 BOSS直聘 / 猎聘 的职位详情页
2. 点「存入职位库」按钮
3. 页面提示：已存入 / 已存在（自动去重）
4. 打开 DSH 侧栏的「求职助手」，在「职位库」标签查看

## 说明

- 插件只提取你**当前打开**的页面内容，不做自动搜索或批量抓取。
- 相同职位（公司 + 职位名 + 职位描述）自动去重，不会重复保存。
- 保存后的职位可在「职位库」点「批量打分」，由 DSH 中配置的模型对照已确认能力打分。
- 提取失败时（平台页面改版导致选择器失效），可手动复制职位原文，在插件「职位库」页粘贴存入。
